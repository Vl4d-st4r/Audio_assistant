# Audio_assistant
Стек: Python, SpeechRecognition, Vosk (Kaldi), OpenAI API, pyttsx3, python-dotenv.
Что умеет ассистент:
🎤 Распознает речь с умным fallback’ом: если пропадает сеть, система бесшовно переключается на локальную модель Vosk.
🧠 Отвечает на вопросы через OpenAI API и озвучивает результат.
🌐 Взаимодействует с внешними сервисами: ищет информацию в Google/Wikipedia, открывает видео на YouTube, показывает погоду и ищет людей в соцсетях.
